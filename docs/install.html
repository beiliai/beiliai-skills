安装贝礼 AI 技能

在 Claude Code、Codex、WorkBuddy 等 Agent 中直接对话拆解视频：爆款分析、分镜、文案、BGM。当前版本 v1.5.0。

一句话安装

把下面这句话发给你的 Agent，它会自动下载技能并引导你在浏览器里授权登录，不需要复制任何密钥。

请按 https://www.beiliai.com/agent/install.md 安装贝礼 AI 技能

授权登录是怎样的

  1. Agent 给你一个链接和授权码，在浏览器打开链接。
  2. 用手机号验证码登录；没有账号会自动注册，新用户赠送体验积分。
  3. 核对页面上的授权码和 Agent 给的一致，点“授权”，回到 Agent 继续即可。

授权会在你的账号下生成一把 API 密钥，可以随时在 API 密钥 页面删除，删除后该 Agent 立即失去访问权限。

手动安装

1. 把技能文件下载到客户端的技能目录：

客户端目录
Claude Code~/.claude/skills/beiliai-skills/
Codex~/.codex/skills/beiliai-skills/
其他支持 Skill 的客户端该客户端技能目录下的 beiliai-skills/
# macOS / Linux（以 Claude Code 为例）
D=~/.claude/skills/beiliai-skills
B=https://www.beiliai.com/agent/skill/beiliai-skills
mkdir -p "$D/scripts"
curl -fsSL "$B/SKILL.md" -o "$D/SKILL.md"
curl -fsSL "$B/scripts/beiliai.py" -o "$D/scripts/beiliai.py"
# Windows PowerShell
$D = "$env:USERPROFILE\.claude\skills\beiliai-skills"
$B = "https://www.beiliai.com/agent/skill/beiliai-skills"
New-Item -ItemType Directory -Force "$D\scripts" | Out-Null
Invoke-WebRequest "$B/SKILL.md" -OutFile "$D\SKILL.md"
Invoke-WebRequest "$B/scripts/beiliai.py" -OutFile "$D\scripts\beiliai.py"

2. 授权登录（需要 Python 3.8 及以上）：

python ~/.claude/skills/beiliai-skills/scripts/beiliai.py login

也可以在 API 密钥 页面创建密钥，在终端里设置环境变量 BEILIAI_API_KEY 使用。不要把密钥发到对话里。
